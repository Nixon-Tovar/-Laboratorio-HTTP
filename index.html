Objetivo del proyecto

Construir un sitio web en HTML puro, organizarlo en un repositorio de GitHub y empaquetarlo con un Dockerfile para que cualquier persona pueda replicarlo en otra máquina con un solo comando.

¿Qué tiene que ver con la Capa 7?

La capa de Aplicación es la más cercana al usuario. Cuando abres este sitio, tu navegador (cliente) envía una petición HTTP al servidor web Nginx que corre dentro de un contenedor Docker, y el servidor responde con estos archivos HTML.

  1. El navegador resuelve el nombre del host (DNS) o usa localhost.
  2. Se abre una conexión TCP al puerto 8001 del equipo anfitrión.
  3. Docker redirige ese puerto al puerto 80 del contenedor.
  4. El navegador envía GET /index.html HTTP/1.1.
  5. Nginx responde HTTP/1.1 200 OK con el documento HTML.
Cliente (navegador)  --->  GET /index.html  --->  Nginx (contenedor :80)
Cliente (navegador)  <---  200 OK + HTML    <---  Nginx (contenedor :80)
