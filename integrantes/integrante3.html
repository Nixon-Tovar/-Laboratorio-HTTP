Lo que aprendí en el curso: servicios de la capa de aplicación

Aprendí que la capa 7 es donde viven los servicios que usamos todos los días: la web (HTTP/HTTPS), la resolución de nombres (DNS), el correo (SMTP) y la asignación automática de direcciones (DHCP). También vimos cómo publicar un sitio web con un servidor como Nginx dentro de un contenedor Docker.

Una respuesta HTTP típica se ve así:

HTTP/1.1 200 OK
Server: nginx
Content-Type: text/html

Conceptos clave

HTTP
Protocolo petición/respuesta para transferir páginas web (puerto 80).
DNS
Traduce nombres de dominio a direcciones IP (puerto 53).
Docker
Empaqueta una aplicación con todo lo necesario para ejecutarse igual en cualquier máquina.
Códigos de estado
200 OK, 301 redirección, 404 no encontrado, 500 error del servidor.
